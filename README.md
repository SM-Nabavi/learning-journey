# Learning Journey

A personal repository documenting my journey in programming, systems, and cybersecurity.

This repository is a record of what I learn, build, experiment with, break, debug, and understand along the way.

## 🎯 Purpose

I created this repository to:

* document my learning process
* keep track of concepts and technologies I learn
* practice by writing small programs and experiments
* document mistakes, problems, and solutions
* build a history of my technical growth

This is not intended to be a collection of copied tutorials.
The goal is to document things I have actually studied, implemented, tested, or understood.

## 🧭 Current Path

My current learning path is:

**C → Systems Programming → Cybersecurity**

**Deep Learning → PyTorch → Practical Projects**

I am currently focusing on learning C deeply, especially the parts that will help me understand systems and low-level programming.

Alongside this, I am continuing my study of deep learning and PyTorch through practical learning and experiments.
