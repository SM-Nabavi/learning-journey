# Python Dependency Management

**Date:** 1405-6-30

## Problem
در هنگام نوشتن مستندات پروژه برای فایل `requirements.txt` با مشکلی مواجه شدم.

نمی‌دانستم کتابخانه‌هایی که استفاده کرده‌ام چه وابستگی‌های دیگری دارند و چه نسخه‌هایی از کتابخانه‌ها با یکدیگر سازگار هستند. در نتیجه مجبور بودم این موارد را به صورت دستی بررسی کنم و برای پیدا کردن نسخه‌های مناسب، جستجوهای زیادی انجام دهم.

حتی بعد از این بررسی‌ها هم نمی‌توانستم با اطمینان بگویم که نسخه‌های انتخاب‌شده با یکدیگر سازگار هستند.

در همین فرایند با `pip-tools` و روش استفاده از `requirements.in` آشنا شدم.

## requirements.in

`requirements.in` شامل وابستگی‌های مستقیم پروژه است؛ یعنی کتابخانه‌هایی که مستقیماً در پروژه از آن‌ها استفاده می‌کنم.

برای مثال:


```text
requests
numpy
pandas
```
در این فایل معمولاً فقط وابستگی‌های مستقیم پروژه را مشخص می‌کنم.

## requirements.txt

requirements.txt فایل نهایی وابستگی‌های پروژه است.

در آن علاوه بر وابستگی‌های مستقیم، وابستگی‌های موردنیاز آن‌ها نیز مشخص می‌شوند و نسخه‌های مشخصی برای نصب ثبت می‌شوند.

این فایل می‌تواند با استفاده از pip-tools و بر اساس requirements.in تولید شود.

## Workflow

روند کاری که یاد گرفتم:
```text
requirements.in
       ↓
    pip-tools
       ↓
requirements.txt
```
ابتدا وابستگی‌های مستقیم را در requirements.in قرار می‌دهم.

سپس با استفاده از pip-tools، وابستگی‌ها resolve می‌شوند و فایل requirements.txt تولید می‌شود.

## Example

فرض کنیم پروژه مستقیماً از این کتابخانه‌ها استفاده می‌کند:
```text
requests
pandas
```
این موارد را در requirements.in قرار می‌دهم و سپس با pip-tools فایل requirements.txt را تولید می‌کنم.

فایل خروجی می‌تواند شامل خود این کتابخانه‌ها و وابستگی‌های موردنیاز آن‌ها با نسخه‌های مشخص باشد.

## What I Learned
- تفاوت بین وابستگی‌های مستقیم و وابستگی‌های غیرمستقیم را بهتر فهمیدم.
- requirements.in را برای مشخص کردن وابستگی‌های مستقیم پروژه استفاده می‌کنم.
- requirements.txt می‌تواند نتیجه resolve شدن وابستگی‌ها و مشخص شدن نسخه‌های نصب باشد.
- pip-tools می‌تواند فرایند تولید requirements.txt را ساده‌تر و قابل تکرارتر کند.
- لازم نیست تمام وابستگی‌های غیرمستقیم را به صورت دستی پیدا و وارد کنم.
## Useful Commands
برای تولید یا به‌روزرسانی requirements.txt از روی requirements.in.

```bash
pip-compile requirements.in
```
برای هماهنگ کردن محیط مجازی با وابستگی‌های مشخص‌شده در requirements.txt.
```bash
pip-sync requirements.txt
```
